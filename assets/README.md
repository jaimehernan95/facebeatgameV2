# Repository Visual Assets

Drop the visual launch assets for GitHub and Show HN into this `assets/` directory:

1. **`demo.gif`** (Referenced in `README.md` at `width="720"`)
   - Recommended size: `720px` wide (16:10 or 16:9), 15–20 FPS, ~5–10 seconds showing live webcam tracking + falling 4-lane notes + `PERFECT` / `GREAT` combo bursts.
2. **`og-banner.png`** (GitHub Repository Social Preview)
   - Required dimensions: **`1280x640`** PNG (`2:1` aspect ratio).
   - Theme: **Red-themed arcade social preview banner** (`#EF4444` / `#DC2626` crimson accent glow over deep slate `#0B1120`) featuring the **FaceBeat Arcade** title and crisp tagline (`Your Face Is the Controller · 100% Local Webcam`).
   - Upload via GitHub: **Repository Settings → General → Social preview → Edit → Upload an image**.
